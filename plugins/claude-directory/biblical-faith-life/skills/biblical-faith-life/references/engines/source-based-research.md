# Source Based Research

Build a claim ledger with evidence type, source ID, exact locator, accessed date, excerpt, and confidence. Prefer primary sources. Verify the source actually supports the claim and record counterevidence. Separate verified observation, interpretation, inference, uncertainty, association, and causation. The runtime verifies excerpt membership and source references; this proves internal consistency, not source authenticity or the correctness of an inference. Human/model review remains required for externally acquired evidence.
