# Declared local runtime — not included in this edition

The skills-only directory edition declares no MCP server. It launches nothing, opens no port, writes no file, reads no credential and makes no network request.

The tool names that some skills mention (bfl_status, bfl_validate, bfl_library_ingest, bfl_library_search, bfl_library_get, bfl_workflow_start, bfl_workflow_record, bfl_workflow_status, bfl_visual_export, bfl_draft_preview, bfl_draft_submit and bfl_draft_verify) belong to the full edition for Claude Code, published from https://github.com/alexjnapster/biblical-faith-life. In this edition they are unavailable. State that plainly when a task depends on one of them and continue with a text answer or draft; do not describe an operation as executed.
