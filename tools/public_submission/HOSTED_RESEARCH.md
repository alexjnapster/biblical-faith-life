# Hosted public-source research scope

This public connector exposes only bfl_catalogue, bfl_sections, bfl_search_sources and bfl_read_unit over the separate `/api/public-research/mcp` interface. They read the same twelve already-public publisher-supplied governing documents. No account or personal data is needed. Search results are locators, not conclusions; read complete relevant argument units and amendments, follow pagination, and distinguish publisher convictions from independent verification. A source hash proves byte consistency, not theological truth, authorship or actual independent review.

Do not call these tools for newly published papers, live DOI verification, private libraries or congregation records. Explain those limits and use only separately available, authorized host capabilities where appropriate. Do not send manuscript envelopes or personal records to this public interface. It provides no audit, write, private-library, account, arbitrary URL/file, Church UA or publishing operation.

The original `/mcp` audit service remains separately protected by Sites-managed authentication. This public connector does not grant access to it and must not claim an authenticated audit was run. The complete bundled Python engines and storage/export workflows still require an actual code-capable host and authorized local workspace. If that executor is absent, provide a useful draft or specification and state exactly which runtime step was not executed. Never convert missing runtime execution into a passed gate. Church UA uses only separately configured authorized access and remains draft-first.
