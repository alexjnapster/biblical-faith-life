Privacy policy

Effective 18 October 2026. Publisher and contact: Oleksandr Rodichev, alexandr.rodichev@gmail.com. This policy covers the Biblical Faith Life plugin packages, this plugin website and the optional Biblical Faith Life Research hosted service.

Where information goes

The downloadable packages contain instructions, reference documents and local Python tools. The Claude desktop runtime uses its declared local MCP server. The separate optional hosted research service processes tool requests as described below. Neither package adds an analytics client. Your prompts, uploaded files, model answers and any host tool use are processed by the host you select, such as ChatGPT or Claude, under that provider’s account settings and policies. The publisher does not automatically receive your conversations from this package.

Local files and version history

If you use the optional knowledge base or workflow tools, they write documents, provenance, local owner labels, immutable versions and checkpoints into the workspace you select. Files can contain personal information you supply. They are retained until you remove the relevant files or library, including historical versions and backups. Restoring or updating a document creates or preserves history; it is not an erasure operation. The package has no automatic expiry period. Your operating system, backups, cloud-synced folders and host may keep additional copies. Uninstalling the plugin does not necessarily delete your workspace.

Hosted research service

The optional Biblical Faith Life Research service runs on OpenAI Sites infrastructure using Cloudflare Workers. Public source tools retrieve the publisher-supplied reference corpus. The evidence audit requires ChatGPT sign-in and receives the evidence envelope you explicitly submit. The service receives platform-provided account identity for authorization; its code does not store account identity, manuscripts, audit envelopes or tool responses in a database or file store. Processing is transient in the application. Hosting providers may process network requests, authentication information and operational logs under their own policies; this policy does not promise deletion periods for infrastructure the publisher does not control. Your host can retain the conversation and tool results. Submit synthetic or non-sensitive manuscripts. Do not send passwords, API keys, congregation records, children’s records or sensitive pastoral details. The hosted service cannot access your local library and has no Church UA credentials or publishing tool.

Optional external services

If you authorize Church UA integration, the explicitly configured local tool sends the reviewed content and the authentication necessary for that request to the HTTPS Church UA origin you configure. It can read back recent content to verify draft status. Church UA and the relevant congregation control their server-side data and retention. Installation alone grants no Church UA access. Research or source verification can also use tools supplied by your host; their requests are governed by the host and destination service. No user credentials are bundled in the package. In the current Claude MCP package, an optional existing Church UA key is supplied through the host’s sensitive plugin configuration and is passed only to the declared local server. It is sent only to the configured Church UA origin for an authorized request; ambient credential discovery is not used by that server.

Website and support

This static site is hosted by GitHub Pages and has no publisher-added analytics, advertising or tracking cookies. GitHub may process network information under its own privacy statement. If you email support or open an issue, the information you provide is processed through email or GitHub to handle your request and is retained until removed through those systems; no fixed automatic deletion period is promised. Public GitHub issues are visible to others. The publisher does not sell personal information through this plugin.

Your choices

Use non-sensitive examples where possible. You can stop using the plugin, remove local libraries and backups you control, manage conversations through your host, and request deletion of support correspondence at the contact above. Requests concerning host or Church UA records must also be directed to the service that holds them. This plugin is intended for adult teachers and ministry workers preparing materials, including materials for young people; it is not intended to collect children’s personal information. Do not submit children’s private records.

Changes

Updates to this policy will appear here with a revised effective date. Review the policy before enabling a new integration.
